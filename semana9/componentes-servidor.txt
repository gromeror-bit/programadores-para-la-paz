Sistema operativo:
Es el software principal que administra los recursos del computador y permite ejecutar programas y servicios.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador, especialmente en servidores.

Aplicación server.js:
Es el archivo que contiene el código del servidor. Define las rutas y las respuestas que reciben los usuarios.

Puerto:
Es un punto de comunicación que utiliza el servidor para recibir solicitudes. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros de eventos y actividades del servidor. Ayudan a detectar errores y monitorear el funcionamiento del sistema.
